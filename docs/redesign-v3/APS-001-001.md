# Purpose

This document establishes the governance, ownership, scope and authority of the AskChetna Product Specification (APS).

APS is the highest-level product specification repository for the AskChetna ecosystem.

Every future design, engineering, UX and AI implementation document references APS.

No implementation should contradict an approved APS document.

---

# Scope

APS governs the complete AskChetna ecosystem including, but not limited to:

- Marketing Website
- Web Application
- Android Application
- iOS Application
- Shared Design System
- Shared Component Library
- Shared Asset Library
- AI Prompt Library
- Technical Standards
- Development Standards
- QA Standards
- Accessibility Standards
- Future Products

# Documentation Principles

APS follows these principles.

APS-PRN-0001

Documentation is part of the software architecture.

---

APS-PRN-0002

Documentation precedes implementation.

---

APS-PRN-0003

Every important decision must be documented.

---

APS-PRN-0004

Every document must be version controlled.

---

APS-PRN-0005

Every requirement must be traceable.

---

APS-PRN-0006

Every platform shares one product identity.

---

APS-PRN-0007

Every implementation must reference APS.

---

APS-PRN-0008

No undocumented feature may be released.
