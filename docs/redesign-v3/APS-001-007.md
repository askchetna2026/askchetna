# Purpose

This section defines every stakeholder and primary user group that the AskChetna platform serves.

Every feature, workflow, interaction, content block and design decision should satisfy at least one documented user persona.

Features that do not solve a documented stakeholder problem should not be implemented.

# Primary User Personas

---

## APS-PER-001

### Explorer

Description

First-time visitor.

Curious.

Has little or no previous experience with AskChetna.

Usually arrives from:

Google

Social Media

Recommendations

Advertisements

Search Results

---

Goals

Understand what AskChetna does.

Explore available tools.

Determine whether the platform is trustworthy.

Try one AI-powered experience.

---

Pain Points

Too many choices.

Unclear value.

Distrust of AI.

Poor first impression.

Confusing navigation.

---

Needs

Simple homepage.

Clear messaging.

Immediate value.

Minimal friction.

Strong trust signals.

---

Business Value

Converts visitors into users.

---

Success Criteria

Explorer understands the platform within ten seconds.

Explorer successfully reaches a useful feature.

Explorer is encouraged to return.
