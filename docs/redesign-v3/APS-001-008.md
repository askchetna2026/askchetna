# Purpose

This section identifies the real-world problems that AskChetna is expected to solve.

Every feature, workflow, component and user interaction implemented anywhere in the product must solve one or more documented user problems.

No feature should exist without traceability to a documented problem.

# User Problem Register

---

## APS-PROB-0001

### Users do not know where to begin.

Observed Behaviour

New visitors often leave websites within a few seconds because they cannot immediately understand:

- what the platform offers
- why they should trust it
- where they should start

Root Cause

Poor first impression.

Weak information hierarchy.

Too many competing actions.

Desired Outcome

Visitors immediately understand:

- What AskChetna is.
- Why it is useful.
- What they should do next.

Primary Solution

Clear homepage.

Focused hero.

Strong navigation.

Trust indicators.

Progressive disclosure.

Primary Personas

Explorer

Knowledge Seeker

Affected APS

APS-006

APS-004

APS-005

Priority

Critical

## APS-PROB-0002

### Users do not trust AI.

Observed Behaviour

Many users hesitate before interacting with AI.

Root Cause

Poor presentation.

Lack of transparency.

Overly technical language.

Artificial looking interfaces.

Desired Outcome

Users feel comfortable asking questions.

Primary Solution

Professional design.

Editorial presentation.

Human-centred language.

Real photography.

Clear explanations.

Affected Personas

Explorer

Returning User

Premium User

Priority

Critical

## APS-PROB-0003

### Users become overwhelmed.

Observed Behaviour

Users abandon products with:

too many choices

long forms

large menus

complicated interfaces

Root Cause

High cognitive load.

Desired Outcome

Simple interactions.

One primary task per screen.

Primary Solution

Minimal navigation.

Large spacing.

Simple workflows.

Clear hierarchy.

Progressive disclosure.

Priority

Critical

---

Restart conversations.

Desired Outcome

Continue where they left off.

Primary Solution

Dashboard.

History.

Bookmarks.

Saved sessions.

Recently viewed.

Priority

High
