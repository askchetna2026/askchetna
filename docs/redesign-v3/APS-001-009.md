# Purpose

This document defines how AskChetna will exist across multiple platforms while remaining a single product.

The objective is not to create three different products.

The objective is to create one product delivered through three native experiences.

Every future platform must inherit the AskChetna Design System while respecting native platform expectations.

# Platform Philosophy

Every platform should feel native.

Users should never think:

"I am using a website inside an app."

Instead they should think:

"This feels like AskChetna."

# Shared Component Policy
