# Purpose

The homepage is the most important page of AskChetna.

It has only four objectives.

1. Build Trust
2. Explain the Platform
3. Encourage First Interaction
4. Convert Visitors into Users

Everything else is secondary.

---

# Design Philosophy

The homepage should feel like opening a beautifully designed premium magazine.

It should never feel like:

❌ SaaS Dashboard

❌ Landing Page Template

❌ WordPress Theme

❌ AI Generated Website

Instead it should feel

✓ Editorial

✓ Premium

✓ Calm

✓ Human

✓ Elegant
