# Chapter 1 — Introduction

## 1.1 Purpose

This document defines every visual, structural and interaction rule used throughout the AskChetna platform.

Every designer, developer and AI coding assistant must follow this specification.

This document overrides personal preferences.

If something is not documented here, it should not be invented during implementation.

---

## 1.2 Vision

AskChetna is not designed to look like an AI product.

It is designed to feel like a premium editorial publication that happens to be powered by AI.

Visitors should notice:

• Beautiful typography

• Elegant layouts

• Calm interfaces

• Warm photography

• Thoughtful spacing

• Excellent readability

before they notice the technology.

Technology is the engine.

Design is the experience.

---

## 1.3 Experience Statement

The website should create the same emotional response as walking into:

- a beautifully designed bookstore

- a premium wellness studio

- a luxury journal shop

- a quiet reading room

The experience should never feel noisy.

Every screen should invite exploration.

# Chapter 2 — Design Vision

## 2.1 Design Goal

Create the most elegant AI guidance platform available on the web.

Every page should communicate:

Trust.

Calm.

Warmth.

Professionalism.

Timelessness.

The content should become the focus.

Whitespace is not empty space.

Nothing should feel crowded.

+

Luxury Wellness

+

Human Photography

+

Modern Frontend

+

Minimal Ornamentation

=

AskChetna

# Chapter 4 — Design DNA

The following rules define the identity of AskChetna.

These are mandatory.

## Rule 1

Everything must feel handcrafted.

Never AI generated.

---

## Rule 2

Photography always has priority over illustration.

Illustrations support content.

Photography leads the experience.

---

## Rule 3

Editorial typography is the hero.

Large headings.

Generous spacing.

Readable paragraphs.

Excellent hierarchy.

---

## Rule 4

Every page uses the same rhythm.

Spacing.

Padding.

Margins.

Typography.

Cards.

Buttons.

Everything follows the same visual system.

---

## Rule 5

Every component should be reusable.

Avoid creating unique one-off UI elements unless absolutely necessary.

---

## Rule 6

Every design decision should answer one question:

"Does this increase trust?"

If not,

remove it.

---

## Rule 7

Decoration should never compete with content.

Decorative elements exist to enhance the reading experience, not distract from it.

---

## Rule 8

The interface should encourage slower reading.

Users should never feel rushed.

Generous spacing and balanced layouts should naturally reduce cognitive load.

---

# Chapter 5 — Design Constraints

The following are prohibited unless explicitly approved.

❌ Neon colours

❌ Heavy gradients

❌ Glassmorphism

❌ Excessive blur

❌ Cartoon illustrations

❌ Generic AI artwork

❌ Random icon styles

❌ Different border radius values across components

❌ Different shadows across pages

❌ Multiple button styles solving the same purpose

❌ Decorative animations

❌ Infinite scrolling effects

❌ Autoplay video backgrounds

❌ Flashing elements

❌ Text over busy images

❌ Inconsistent spacing
