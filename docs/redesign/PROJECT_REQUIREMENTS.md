# 1. Project Objective

The objective of this project is to redesign AskChetna into a premium, modern, scalable AI-powered guidance platform with a consistent design language across all pages.

This is a complete UX, UI and frontend redesign.

The redesign must improve:

- User Experience
- Visual Identity
- Performance
- Accessibility
- SEO
- Mobile Experience
- Code Maintainability
- Component Reusability

---

# 2. Existing Problems

The current website has the following issues that need to be addressed.

## Visual

- Visual inconsistency between pages
- Limited design hierarchy
- Generic AI-generated appearance
- Weak premium feel
- Inconsistent section spacing
- Limited use of imagery
- Weak storytelling

---

## UX

- Homepage does not immediately communicate value
- Navigation hierarchy can be simplified
- Calls-to-action need better placement
- Better trust-building sections required
- Improve content discoverability

---

## Technical

- Components should become reusable
- Remove duplicated styling
- Introduce design tokens
- Standardise layouts
- Improve responsiveness
- Optimise images

# 13. Coding Requirements

Use TypeScript.

Use React.

Use Next.js App Router.

Use Tailwind CSS.

Avoid inline styling.

Avoid duplicated code.

Use semantic HTML.

Use reusable components.

Follow ESLint.

Follow Prettier.

---

# 14. AI Coding Requirements

All AI coding tools must

Read the Design Specification first.

Read the Component Library.

Read the Design Tokens.

Never invent colours.

Never invent typography.

Never invent spacing.

Never invent components.

Always reuse existing components.

Never hardcode dimensions.

Always use design tokens.

---

# 15. Success Metrics

The redesign is considered successful when

✓ Every page follows the design system.

✓ No inconsistent components exist.

✓ Navigation is intuitive.

✓ Homepage clearly communicates value.

✓ Mobile experience is excellent.

✓ Performance targets are achieved.

✓ Documentation is complete.

✓ AI tools can generate new pages consistently.
