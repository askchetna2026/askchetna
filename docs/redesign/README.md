# AskChetna Premium Redesign

> **Version:** 1.0.0  
> **Status:** Design Phase  
> **Project Type:** Complete UI/UX & Frontend Redesign  
> **Repository Owner:** AskChetna Team

---

# Overview

This repository contains the complete design, UX, frontend architecture, documentation, visual guidelines, and AI coding instructions required to redesign the AskChetna platform.

This is **not** a frontend code repository.

It is the **single source of truth** for the complete redesign of AskChetna.

Every design decision, UI component, colour, typography rule, animation, layout, image style, and coding standard will be documented here before implementation.

The purpose is to ensure that every AI coding tool (Codex, Cursor, Claude Code, Gemini CLI, Windsurf, Lovable, Bolt, etc.) and every human developer follows the exact same design language throughout the project.

---

# Project Goal

Create one of the most premium AI-powered guidance platforms on the web.

The redesigned website should feel:

- Calm
- Elegant
- Editorial
- Human
- Warm
- Modern
- Premium
- Trustworthy

The experience should never feel like a generic AI-generated website.

---

# Design Philosophy

The project follows one simple philosophy.

> **Design should communicate trust before functionality.**

Visitors should immediately feel that AskChetna is carefully crafted, thoughtful, and professional.

The interface should disappear into the background so users can focus on guidance, self-discovery, and learning.

---

# Primary Objectives

- Completely redesign the visual identity.
- Build a reusable design system.
- Create a scalable component library.
- Standardise every UI element.
- Improve usability.
- Improve accessibility.
- Improve responsiveness.
- Improve SEO.
- Improve frontend performance.
- Create documentation suitable for AI-assisted development.

---

# Project Principles

Every design decision must follow these principles.

1. Simplicity before decoration.
2. Editorial layouts over traditional landing pages.
3. Real photography over AI-generated artwork.
4. Human-centred design.
5. Calm interfaces.
6. Large whitespace.
7. Elegant typography.
8. Consistent components.
9. Accessibility first.
10. Performance first.

# Design Quality Goals

The redesigned website should achieve:

- Premium visual identity
- WCAG AA accessibility
- Responsive layouts
- High readability
- Strong visual hierarchy

- Fast page loading

---

# Success Criteria

The redesign is considered complete when:

- Every page follows the same design language.
- Every component is reusable.
- Every image follows the image guide.
- Every animation follows the motion guide.
- Every page passes accessibility review.
- Every page is responsive.
- Lighthouse score exceeds 95 where practical.
- Documentation is sufficient for AI-assisted development without ambiguity.
