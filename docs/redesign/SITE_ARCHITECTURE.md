# Purpose

This document defines the complete information architecture of AskChetna.

It acts as the blueprint for:

- Navigation
- Sitemap
- Page hierarchy
- User journeys
- Internal linking
- Global layout consistency
- Future scalability

Every new page added to the platform must fit into this architecture.

---

# Information Architecture Principles

The architecture follows five principles.

## 1. Simple Navigation

Users should never feel lost.

Navigation should always answer:

- Where am I?
- What can I do next?
- How do I go back?

---

## 2. Progressive Discovery

Do not expose everything immediately.

Introduce features gradually as users explore.

---

## 3. Consistency

Every page follows the same layout pattern.

Users should never need to "learn" navigation again.

---

## 4. Scalability

New AI tools should be added without redesigning navigation.

---

## 5. SEO Friendly

Every important page should have a dedicated URL.

Avoid hidden content.

---

# Architecture Rules

Every page must answer:

- Why does this page exist?
- Who is it for?
- What action should the visitor take?
- Which page should they visit next?

If a page cannot answer these questions clearly, it should be redesigned or removed.
